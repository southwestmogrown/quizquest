# Welcome to JavaScript

JavaScript is the most widely used programming language on the planet. It runs in every web browser, powers server-side applications through Node.js, and is the backbone of modern web development.

## Why Learn JavaScript?

- **Universal reach** — JavaScript runs everywhere: browsers, servers, mobile apps, even IoT devices.
- **Instant feedback** — you can see results immediately in the browser or a terminal.
- **Massive community** — millions of developers, thousands of frameworks, and endless learning resources.

## What You'll Build

In this course you'll start with the fundamentals: console output, variables, and basic expressions. Each lesson includes a hands-on code challenge that runs right in your browser using Node.js.
