# Welcome to Python

Python is one of the most popular programming languages in the world — and for good reason. Its clean, readable syntax makes it a fantastic first language, and it powers everything from web apps and data science to AI and automation.

## Why Learn Python?

- **Readable syntax** — Python reads almost like English, so you can focus on problem-solving instead of fighting the language.
- **Huge ecosystem** — thousands of libraries for web development, data analysis, machine learning, and more.
- **In-demand skill** — Python developers are sought after in nearly every industry.

## What You'll Build

In this course you'll start with the basics: printing output, working with variables, and writing simple programs. Each lesson includes a hands-on code challenge that runs right in your browser.
